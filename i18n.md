# i18n Architecture – Radio Library

## Overview

The Radio Library frontend supports multiple languages (EN/DE) via a lightweight, custom i18n system built on **React Context** and **JSON translation files**. No third-party i18n library is required.

---

## Directory Structure

```
frontend/src/i18n/
├── en.json             # English translations (default)
├── de.json             # German translations
└── LanguageContext.jsx # React Context, Provider, useLanguage hook
```

---

## Components

### `LanguageContext.jsx`

Provides:
- `LanguageProvider` – wraps the app, manages language state (default: `'en'`)
- `useLanguage()` – hook returning `{ t, language, setLanguage }`

```jsx
const { t, language, setLanguage } = useLanguage();
t('key')                     // → translated string
t('key', { name: 'Foo' })    // → string with {name} interpolated
```

### Translation Files (`en.json`, `de.json`)

Flat key-value JSON files. Keys use dot-notation to group by feature area:

```json
{
  "header.filter":    "Filter (F)",
  "player.playPause": "Play / Pause (Space)",
  "confirm.delete":   "🗑️ Delete"
}
```

**Template variables** use `{varName}` syntax:
```json
{ "table.pagination.info": "Page {page} / {totalPages} · {total} Songs" }
```
Called as: `t('table.pagination.info', { page, totalPages, total })`

---

## Language Switcher

Located in `AppHeader.jsx`, right side of the navigation bar:

- 🇬🇧 – switches to English (`language === 'en'`)
- 🇩🇪 – switches to German (`language === 'de'`)

Active language flag is fully opaque; inactive is 45% opacity.

---

## Integration in App

`App.jsx` wraps the entire app with `LanguageProvider`:

```jsx
export default function App() {
  return (
    <LanguageProvider>
      <AppInner />
    </LanguageProvider>
  );
}
```

Every component that needs translations imports `useLanguage`:

```jsx
import { useLanguage } from '../i18n/LanguageContext';

function MyComponent() {
  const { t } = useLanguage();
  return <button title={t('header.filter')}>🔍</button>;
}
```

## Key Namespaces

| Prefix       | Covers                              |
|--------------|-------------------------------------|
| `app.*`      | App title                           |
| `header.*`   | AppHeader navigation                |
| `help.*`     | Keyboard shortcuts help overlay     |
| `table.*`    | SongTable columns, pagination       |
| `player.*`   | Player controls, clip mode          |
| `confirm.*`  | ConfirmModal                        |
| `filter.*`   | FilterModal                         |
| `sort.*`     | SortOrderModal                      |
| `meta.*`     | MetaEditModal                       |
| `playlist.*` | PlaylistManager                     |
| `recording.*`| RecordingControlDialog              |
| `station.*`  | StationEditModal                    |

## Adding a New Language

1. Copy `en.json` to e.g. `fr.json`
2. Translate all values
3. In `LanguageContext.jsx`, add `import fr from './fr.json'` and add `fr` to the `translations` object
4. Add a flag button in `AppHeader.jsx`

---

## Notes

- The default language is `'en'` (English). UI falls back to the English translation if a key is missing in the active language.
- Language selection is stored in React state (in-memory). To persist across page reloads, add `localStorage` support in `LanguageContext.jsx`.
